# 8 周训练路径（不是速成保证）

你已经有 Linux/Python/C++ 经验，C++ 一段时间不用后恢复手感：不建议把第一阶段拖到几个月。每阶段的文档阅读材料、五问卡和练习步骤见 [READING_AND_PROGRESSION.md](READING_AND_PROGRESSION.md)。

| 周 | 重点 | 核心可执行训练 | 实战/源码 | 退出门槛 |
|---|---|---|---|---|
| 1 | RAII、对象生命周期、移动语义 | 01,02,03,04 + 13–28 挑 4 道 | STL vector 对照 | 03 类型可用于非平凡类且无明显泄漏 |
| 2 | 接口、解析、安全边界、工程 | 05,06,07 + 29–44 挑 4 道 | 1 个多 target CMake 工程 | 能说明所有权与错误通道 |
| 3 | 并发、锁与任务 | 08,09,10,12 + 45–52 挑 4 道 | ThreadPool 与 ROS2 Executor 对比 | 能解释 close/shutdown 所有竞争 |
| 4 | 性能、回归、源码阅读 | 11 + 53–60 挑 4 道 | LevelDB Put/Get 追踪 | 跑 ASan/TSan，完成一份性能记录 |
| 5 | 组件二阶段 I | C01、C02 或 C03 | 无 ROS 本机依赖先写 C++ 组件 | API + 构建 + 错误路径 + 自动测试 |
| 6 | ROS2 基础 | C06 | publisher/subscriber/参数/Launch | ROS2 环境中 3 节点流水线跑通 |
| 7 | ROS2 并发与诊断 | C07、C08 | Executor + QoS/时间戳/TF2 | 给出可重复实验数据，不只背 API |
| 8 | 融合项目与作品集 | C09（可选 C10 LevelDB） | GitHub README、架构图、性能日志 | 无 AI 从空骨架完成一个小功能 |

### 时间安排（每天 4～6 小时）
- 核心实现 90 分钟；测试+调试 60～90 分钟；源码阅读 45～60 分钟；工程整合 60～120 分钟。
- 不会的内容 20～40 分钟先查标准库文档，再给 AI 描述问题和实验结果，只索取下一层提示。
- 每周一次「无 AI」验收（45～90 分钟）：从零写一个新变种，而非背已写代码。

### 优先级裁剪
- 求职时间紧：优先 01–09、12，开放题仅做高风险项；同时从第 2 周启动 C06 ROS2 项目。
- 深入机器人控制：后续补 Eigen、时间同步、TF2、控制理论、实时系统；本仓库主攻 C++ 工程基准，不声称覆盖控制算法。
- 走 Agent Security：优先 C03、C05、C09，将输入验证、线程隔离、边界权限与可观测性用于机器人 Agent。
