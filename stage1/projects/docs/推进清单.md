# 推进清单

> 把 `docs/ros2衔接评估.md` 的重排路线图变成**可逐条打勾的表单**。
> 目标：按顺序、由简到深、快速进阶；每一关的产出都能「跑起来 / 玩起来」，并**咬合**下一关，不割裂。
> 出处标注指向 `docs/cpp2.md`（项目）与 `docs/专项训练.md`（模块）。

## 怎么用这份表单

1. **一关一关来**：上一关的「过关门」达标，才进下一关。
   - 想先快速恢复手感：用 `exersize/00-README.md` 的 L1–L4 加速副本（先读 `reference/pXX` → 在 `exersize/sprint/` 盲写 → diff），它横跨本表第 2–5 关，不另起课程。
2. **先跑通再打磨**：每关先出 `v0`（能跑），再按核查点加固——让进步看得见。
3. **🎉 = ROS2 插入点**：早引入，别等最后；从此每个项目都能往 ROS2 上挂。
4. **每关都走同一套 SOP**（下方「每关统一动作」），做完在关内打勾。
5. **横切模块**随用随练，不单独成关。

## 两周冲刺（L1–L4）的 P0 优先序

> 两周计划**不按项目顺序排，按硬核能力排**。完整实操卡（步骤 / 用例 / 预期 / 过关门 / 每日模板）见 **[两周P0冲刺.md](两周P0冲刺.md)**。

| P0 | 能力 | 载体（L1–L4） | AI 替代性 | 两周内必须产出的证据 |
| --- | --- | --- | --- | --- |
| **P0-1** | 所有权 / 生命周期 / 引用计数 | `UniquePtr` → `SharedPtr/WeakPtr/make_shared` | 【不可替代】 代码可生成，模型不可 | 控制块图 + 24h 盲写 + ASan/TSan 绿 |
| **P0-2** | 内存模型 / happens-before | atomic 三实验 → SPSC | 【不可替代】 最易被 AI 写错 | 三份实验数据 + 内存序逐条配对 |
| **P0-3** | 异常安全 / RAII / 失败路径 | 贯穿 Vec / 指针 / 池 | 【AI辅助】 AI 常写不安全，需你审 | 每个改动操作过 `ThrowOnN` 扫描，`live==0` |
| **P0-4** | 可复现测量 + sanitizer 调试 | ASan/UBSan/TSan/gdb/bench | 【AI辅助】 工具可外包，定位不可 | 10 分钟从报告定位到行 + 前后数据 |
| **P0-5**（条件） | 无锁队列 / 实时约束 | SPSC v2–v4 | 【不可替代】 | 五版对照表 + happens-before 口述 |
| **P1-1** | 类型擦除 + SBO | `Function` / `MoveOnlyFunction` | 【AI辅助】 代码大部分可代 | 小捕获零分配证据 |
| **P1-2** | 并发工程：背压 / 停机 | `ThreadPool` | 【AI辅助】 可代写，状态机自己推 | `shutdown(drain)` 状态机 + TSan |
| **P2** | String-SSO / List / Arena / epoll / WAF | — | 【可外包】 理解即可 | 不投入盲写时间 |

**条件**：走实时控制 / ros2_control → P0-5 是绝对 P0；走插件 / 二次开发 → P1-1 升 P0。共同底线是 **P0-1 / P0-3 / P0-4**。

**一句话**：代码可以让 AI 写，**所有权图、失败路径、内存序配对和 24h 盲写**不能。
