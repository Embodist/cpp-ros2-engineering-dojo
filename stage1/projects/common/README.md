# common/ —— 公共测试夹具

跨项目复用的测试夹具放这里，**每个夹具一个头文件**。写成 header-only，由 CMake 里的一个 interface 目标对外提供（该 CMake 由你自己写）。

> 这些夹具的**实现在 `docs/cpp2.md` 第 1 节有行为规格，需要你自己写**（写测试夹具也是内功训练的一部分）。这里只列清单和约定。

## 必备夹具（行为规格）

| 文件（自己命名） | 行为规格 |
| --- | --- |
| `tracer.hpp` | 静态计数：默认构造 / 拷贝构造 / 移动构造 / 拷贝赋值 / 移动赋值 / 析构的次数，以及当前存活数；每个实例有唯一 id；提供计数清零接口 |
| `throw_on_n.hpp` | 可配置「第 N 次拷贝或构造时抛异常」，用来扫描异常安全的所有抛出点 |
| `move_only.hpp` | 内部持有 `unique_ptr<int>`，不可拷贝、可移动 |
| `noexcept_toggle.hpp` | 用 `bool` 模板参数控制移动构造是否 `noexcept`，用来测容器扩容是搬移还是拷贝 |
| `leak_check.hpp` | 测试前后检查 Tracer 存活数是否归零 |
| `new_counter.hpp` | 重载全局 `operator new` 计数，用来证明「短串零分配 / 运行期零 malloc / MakeShared 少一次分配」 |

## 约定

- 只放**跨项目复用**的东西；某个项目专属的夹具放该项目自己的 `tests/`
- 夹具本身也要有测试（放在本项目里选一个，或建一个专门的夹具测试目标）
- 一旦写了，后面所有项目都用它，不要每个项目再造一份
