# E01 · 变参模板、SFINAE 与 concepts

- **知识域**：Templates, Concepts, API Design
- **类型**：扩展实验题（不提供实现和固定测试）
- **规范参考**：C++ Core Guidelines T 系列（模板）与 Con 系列（concepts）；编号以官方页面为准

## 情境 / 任务

为传感器记录设计一个编译期约束的工厂：

- 用变参模板实现 `make_record(fields...)`，要求每个字段满足明确的 concept（算术、字符串或时间戳可转换）。
- 用折叠表达式实现 `print_fields(record)`，并用 `static_assert` 检查字段数量/类型。
- 分别写一版 SFINAE 重载和一版 concepts 约束，比较两者在错误输入下的诊断可读性。
- 负例必须编译失败，且错误信息能指出违反的约束；不要用无约束的兜底重载。

## 可执行验收

3 个正例（整数、浮点、字符串字段）编译并运行；3 个负例（错误字段类型、字段数量不匹配、不可复制类型）编译失败并保存编译器输出；解释重载决议结果；不使用无约束兜底。

## 提交文件

## 使用 AI 的边界

先提交自己的第一版；让 AI 只审查约束是否过宽/过窄并提出反例，不要直接给完整实现。
