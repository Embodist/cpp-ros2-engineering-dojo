# 42 · 错误通道契约

- **知识域**：Interfaces, Templates, API Design
- **类型**：开放实验题（不提供实现和固定测试）
- **规范参考**：C++ Core Guidelines E.2, E.6

## 情境 / 任务
比较异常、error_code、variant 三类错误通道并实现一个场景。

## 可执行验收
写出错误传播和取消语义，未吞错。独立补充至少两个不在上述要求中的反例，附对应可运行的测试或编译命令；保存实际输出，不得仅写“已验证”。

## 提交文件
- `labs/42/main.cpp` 或分离后的 `include/`、`src/`，本人决定模块结构。
- `labs/42/README.md`：解释为什么这么设计、关键不变量、异常与生命周期。
- `labs/42/evidence.md`：输入、工具命令、实测输出、还未覆盖的条件。

## 使用 AI 的边界
先提交自己的第一版；让 AI 只提出审查问题和测试样例。不要让 AI 一次输出完整实现。
